
# Dataset Information

## Dataset Used
This project uses the Kaggle dataset:

https://www.kaggle.com/datasets/manjilkarki/deepfake-and-real-images

---

## Dataset Description
The dataset contains both real and fake human face images used for deepfake detection.

- Image Format: JPG
- Categories:
  - Real Images
  - Fake Images

---

## Dataset Structure

Dataset/
├── Train/
│   ├── Real/
│   └── Fake/
├── Validation/
│   ├── Real/
│   └── Fake/

---

## Purpose
The dataset is used to train a CNN model for detecting manipulated facial images.
